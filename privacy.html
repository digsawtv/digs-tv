Política de Privacidade — DIGS TV

Última atualização: 25/09/2026

1. Sobre esta Política

Esta Política de Privacidade explica como o DIGS TV trata informações durante sua utilização em servidores da plataforma Discord.

O DIGS TV foi desenvolvido com o princípio de minimização de dados, buscando processar e armazenar somente as informações necessárias para oferecer suas funcionalidades.

2. Informações tratadas

Dependendo das funcionalidades utilizadas, o DIGS TV pode processar ou armazenar:

  • ID do servidor Discord;
  • ID de usuários;
  • ID de cargos;
  • informações necessárias para administrar advertências e ações de moderação;
  • informações necessárias para tickets;
  • dados relacionados a XP, níveis e estatísticas;
  • informações relacionadas a eventos e notificações;
  • informações técnicas necessárias para funcionamento das funcionalidades do bot.

O DIGS TV não solicita nem mantém como parte de seu funcionamento normal informações como:

  • CPF ou RG;
  • endereço residencial;
  • localização GPS;
  • número de telefone;
  • senha;
  • token de autenticação do Discord;
  • dados bancários;
  • informações biométricas.

3. Mensagens

Algumas mensagens podem ser processadas temporariamente para permitir funcionalidades como moderação automática, detecção de spam, sistema de XP e tradução.

O DIGS TV não mantém indefinidamente o conteúdo das mensagens em seu banco de dados como parte dessas funcionalidades.

4. Tradução

Quando a funcionalidade de tradução é utilizada, o texto solicitado pode ser enviado ao serviço de tradução utilizado pelo DIGS TV para realizar o processamento.

Atualmente, a funcionalidade utiliza o endpoint:

https://translate.googleapis.com/translate_a/single

Portanto, o usuário deve considerar que o conteúdo enviado para tradução é processado por um serviço externo.

5. Tickets

O sistema de tickets pode registrar informações necessárias para administrar o ticket, incluindo:

  • ID do servidor;
  • ID do usuário;
  • ID do canal;
  • tipo do ticket;
  • status;
  • data de criação;
  • data de encerramento.

O banco de dados do DIGS TV não registra o conteúdo completo das conversas do ticket como parte desse registro.

6. Sistema de XP e estatísticas

Para fornecer funcionalidades de XP, níveis e estatísticas, o DIGS TV pode armazenar informações como:

  • ID do servidor;
  • ID do usuário;
  • quantidade de XP;
  • nível;
  • quantidade de mensagens contabilizadas.

Esses dados são utilizados para fornecer as funcionalidades correspondentes dentro do servidor.

7. Imagem de boas-vindas

Quando uma pessoa entra no servidor, o DIGS TV pode utilizar temporariamente o avatar disponibilizado pelo Discord para gerar a imagem de boas-vindas.

A imagem é processada para gerar a mensagem visual e não é mantida permanentemente pelo DIGS TV como um cadastro de fotografia do usuário.

8. Backups

O DIGS TV possui uma funcionalidade de backup da configuração do servidor.

Para reduzir a quantidade de informações pessoais armazenadas, os registros de membros incluídos nos backups utilizam apenas:

  • ID do usuário;
  • indicação se a conta é um bot;
  • IDs dos cargos associados.

O backup não inclui, como parte do registro de membros, nome de usuário, nome de exibição, apelido ou data de entrada.

9. Finalidades do tratamento

As informações tratadas pelo DIGS TV são utilizadas para finalidades relacionadas ao funcionamento do aplicativo, incluindo:

  • administração do servidor;
  • moderação;
  • segurança;
  • prevenção de spam e abuso;
  • tickets e suporte;
  • XP e níveis;
  • estatísticas;
  • eventos e notificações;
  • backups;
  • funcionamento das demais funcionalidades disponibilizadas pelo DIGS TV.

10. Compartilhamento com terceiros

O DIGS TV utiliza a API oficial do Discord para funcionar na plataforma.

Além disso, determinadas funcionalidades podem utilizar serviços externos. Atualmente, a funcionalidade de tradução pode enviar o texto solicitado ao serviço externo de tradução descrito nesta Política.

Fora das situações necessárias para o funcionamento das funcionalidades ou exigidas por obrigação legal, o DIGS TV não tem como finalidade comercializar ou vender informações pessoais dos usuários.

11. Retenção e exclusão

Os dados são mantidos pelo período necessário para fornecer as funcionalidades correspondentes ou enquanto forem necessários para as finalidades descritas nesta Política.

Dados que deixarem de ser necessários podem ser removidos conforme os procedimentos de manutenção do serviço.

Solicitações relacionadas aos dados podem ser encaminhadas para:

digsawtv@gmail.com

12. Segurança

O DIGS TV busca aplicar medidas de minimização e proteção dos dados tratados pelo serviço.

O acesso às funcionalidades administrativas também depende das permissões atribuídas pelo Discord e pelas configurações do servidor.

Nenhum sistema conectado à Internet pode garantir segurança absoluta.

13. Discord

O DIGS TV funciona dentro da plataforma Discord e está sujeito às políticas, termos e mecanismos de segurança disponibilizados pelo Discord.

O Discord possui suas próprias políticas de privacidade e tratamento de dados, que são independentes desta Política.

14. Alterações desta Política

Esta Política de Privacidade pode ser atualizada quando houver alterações no DIGS TV, em suas funcionalidades ou no tratamento de informações.

A versão atualizada será disponibilizada no endereço oficial da Política de Privacidade.
